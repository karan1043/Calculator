# Calculator Web App

A simple, responsive, and beginner-friendly web calculator built with HTML, CSS, and JavaScript, and hosted on GitHub Pages.

## Live Demo

Check out the live calculator here: **[https://karan1043.github/Calculator/](file:///G:/CALCULATOR/index.html)**

## Features

- **Basic Arithmetic:** Addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
- **Clear & Delete Controls:** Easily clear the entire screen (`AC`) or remove the last entered digit (`DEL`).
- **Decimal Support:** Perform calculations with floating-point numbers.
- **Responsive Design:** Works smoothly across desktop screens, tablets, and mobile phone.
- **Beginner-Friendly Code:** Clean, well-structured files that are easy to read, customize, and learn from.

## Built With

- **HTML5** – Structure and layout of the calculator buttons and display
- **CSS3** – Styling, grid/flexbox layout, and responsive design
- **JavaScript (ES6+)** – Calculation logic and user interaction handling
